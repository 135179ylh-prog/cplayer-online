# PRD：自助恢复能力

## 目标

为本地优先的 CPlayer 增加一个可下载、可重新导入的本机恢复包，帮助用户在误删、换浏览器或本地数据损坏后恢复自建歌单及其历史版本。

## 范围

- 导出 active 歌单、回收站歌单和 `playlist_versions` 历史快照。
- 导入前完整校验；校验失败不得改动 IndexedDB。
- 导入使用一个 `readwrite` 事务，歌单全部生成新的 `user_pl_` ID。
- 重名自动追加恢复标记“（已恢复）”，回收站状态和删除时间保留。
- 历史快照的 `playlistId` 映射到新歌单 ID。
- 导入不创建 `cloud_outbox`，之后用户编辑恢复副本时才进入正常云同步。
- 保留现有普通“歌单备份”导出/导入，不改变其行为。

## 明确排除

恢复包不得包含 ChKSz API 密钥、API 地址、播放队列、最近播放、播放进度，以及 `cloudOwnerId`、`cloudVersion`、`cloudDirty`、`purgedAt`、`cloud_outbox`。

## 验收标准

1. 桌面和手机资料库都能看到恢复包导出/导入入口。
2. 包含 active、trash、history 的有效恢复包可导出并成功导入。
3. 导入后的记录使用新 ID，历史快照指向新 ID，trash 仍在回收站。
4. 敏感字段和同步队列不会出现在导出 JSON，也不会因导入新增待同步项。
5. 损坏 JSON、错误格式、超限数据均在写库前失败，已有数据逐字节保持不变。
6. 完整 `npm run verify`、桌面浏览器和手机视口测试通过。
