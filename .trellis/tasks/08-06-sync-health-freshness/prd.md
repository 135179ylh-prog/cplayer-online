# PRD：同步健康检查的新鲜待办状态

## 目标

让“一键同步健康检查”在刚发生离线修改、刚登录或页面状态尚未完成异步刷新时，仍能基于同一次 IndexedDB 只读快照给出准确的待同步结论。

## 范围

- 健康检查复用 IndexedDB 检查得到的 `cloud_outbox` 数量，不依赖可能滞后的内存投影。
- 未配置、未登录或已登录但仍有待同步项目时，结果明确显示“需留意”。
- 保持检查只读，不上传、删除、覆盖或读取歌曲内容。
- 桌面和手机浏览器测试覆盖有待办与无待办两种状态。

## 验收标准

1. 检查报告中的数据库待办数量与云同步项显示一致。
2. 有待同步项目时摘要至少包含一项“需留意”，并给出联网/登录/重试建议。
3. 无待办的未配置本机仍显示为可用，不强制登录或联网。
4. 检查前后 IndexedDB、localStorage 和 `cloud_outbox` 内容不变。
5. 桌面、手机定向测试与完整 `npm run verify` 通过。
