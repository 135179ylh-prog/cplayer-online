# PRD：一键同步健康检查

## 目标

在设置里的账号与云同步卡片增加一个只读的“健康检查”，让用户能快速知道本机存储、待同步队列、账号状态、PWA 缓存和自助恢复入口是否可用。

## 范围

- 检查 IndexedDB 是否可读、版本和关键 store 是否存在。
- 显示本机待同步数量及当前本机存储状态。
- 显示云同步配置、登录、同步、冲突和最近成功同步状态；不主动请求云端。
- 检查 Service Worker 是否接管以及同源缓存 API 是否可用。
- 检查恢复包导出、导入预览入口是否存在。
- 允许导出不含密钥、API 地址、队列内容、最近播放、播放进度和歌曲内容的诊断报告。

## 非目标

- 不删除、覆盖、上传或修改任何数据。
- 不把第三方云服务实时可用性作为确定性健康结论。

## 验收标准

1. 桌面和手机均能打开设置并运行检查，结果有明确通过/需留意/受阻说明。
2. 检查失败时仍保留播放器和本机数据可用，报告给出可操作建议。
3. 点击检查前后 IndexedDB、localStorage 和 cloud_outbox 内容不变。
4. 诊断报告只包含状态、数量、布尔值和建议，静态测试确认不含敏感字段或歌曲内容。
5. `node --check js/app.js`、`python tests/verify_features.py`、定向桌面/手机测试及 `npm run verify` 通过。
