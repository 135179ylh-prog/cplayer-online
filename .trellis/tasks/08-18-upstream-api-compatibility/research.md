# 研究记录

## 上游来源

- 公开演示站：`https://cp.chksz.top/`
- 公开仓库：`https://github.com/ChKSz/CPlayer`
- 仓库在本次核对时为 MIT 许可，约 65 stars、6 forks；最新可核实提交包含多音源和 API 响应模块。

## 本次对照结论

- 新站是前端播放器，搜索、歌曲解析和歌词仍依赖上游 HTTP 服务；不是完全不需要 API。
- 新站新增了多音源适配、音质选项和歌曲上下文菜单，但这些会改变歌曲 ID 和部分 API 契约，不能直接覆盖当前项目。
- 当前项目已经使用新的上游服务域名，且本地 API 密钥仍只保存在浏览器 `localStorage`；本次先同步无状态的 HTTP 响应解码模式。

## 安全边界

- 不记录 API 密钥、账号身份、完整音频 URL、歌单内容或播放进度。
- 不读取或改写真实歌单；测试只使用测试响应和测试歌曲。
