# PRD：同步健康检查快照过期提示

## 目标

健康检查是一次只读快照。检查完成后，如果云同步状态或待同步队列发生变化，界面必须明确告诉用户旧报告已过期，避免把旧结果当成当前状态。

## 范围

- 健康检查记录生成时的状态修订号。
- 云同步状态、待同步数量、冲突变化或成功同步后，让已有报告显示“结果已过期”。
- 过期时保留原报告供查看，但禁止把它误认为当前结论；导出按钮重新检查前不可用。
- 桌面和手机覆盖“检查完成 → 本机产生待办 → 报告过期 → 重新检查恢复”的流程。

## 非目标

- 不自动上传、删除、覆盖或重读歌曲内容。
- 不改变同步调度、冲突选择或本机优先策略。

## 验收标准

1. 新检查完成时显示“检查完成”，过期提示隐藏，脱敏报告可导出。
2. 检查后产生新的待同步状态时，旧列表保留但显示“本机状态已变化，请重新检查”，导出按钮不可用。
3. 重新检查后过期提示消失，报告恢复可导出，并使用新的 `cloud_outbox` 快照。
4. 过期提示不包含密钥、地址、账号、队列或歌曲内容。
5. 桌面、手机定向测试与完整 `npm run verify` 通过。
