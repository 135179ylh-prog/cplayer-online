# PRD：恢复包导入预览

## 目标

让本机恢复包在真正写入前先展示恢复内容和命名处理规则，用户确认后才新增歌单；取消或关闭预览时不得改变现有本机数据。

## 范围

- 选择恢复包后先校验并读取内容，不写入 `playlists`、`playlist_versions` 或 `cloud_outbox`。
- 预览活动歌单、回收站歌单、历史版本和重名处理数量。
- 明确恢复是新增副本，不覆盖已有歌单；重名自动使用“（已恢复）”及序号。
- 支持确认、取消、遮罩点击和 Escape 关闭。
- 确认时重新读取当前歌单并生成导入计划，再复用现有原子导入事务。
- 失败时保留预览并显示错误，已有数据不变。

## 排除

- 不改变恢复包格式、字段排除规则、ID 映射规则和云同步规则。
- 不把 API 密钥、API 地址、队列、最近播放、播放进度或 `cloud_outbox` 放入预览状态。

## 验收标准

1. 桌面和手机视口选择有效恢复包后均打开可访问预览弹窗。
2. 预览显示 active/trash/history 数量、重名处理数量和“不覆盖现有歌单”说明。
3. 预览打开和取消前后 IndexedDB 内容逐项一致，`cloud_outbox` 不新增。
4. 确认后才写入新 `user_pl_` ID、回收站记录和映射后的历史版本。
5. 重名确认后使用“（已恢复）”规则；损坏文件仍沿用原错误提示且不打开预览。
6. 完整 `npm run verify`、桌面浏览器和手机视口测试通过。
